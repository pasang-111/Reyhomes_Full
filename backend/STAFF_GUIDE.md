# ReyHomes CMS — Staff guide

## Login
Open `/admin/` and sign in with your staff account.

## Daily workflow
1. **Dashboard** — check Data accuracy + new enquiries
2. **Enquiries** — open New → call/email → set Contacted → notes → Closed
3. **Home designs** — add/edit content following the numbered sections
4. Tick **Published** only when hero image + price + rooms are filled
5. Tick **Featured** only for designs that should appear on the homepage

## Adding a home design (simple path)
1. Title (e.g. The Malaga)
2. Category (Single / Double / Dual Occupancy / Knockdown Rebuild)
3. Price as customers should see it (`$435,000`) — number fills automatically
4. Bedrooms, bathrooms, garage
5. Upload hero image (wide photo)
6. Optional: floor plan, gallery, inclusions
7. Publish

## Units
- House / land size → **m²** (or just the number)
- Frontage / depth / min lot width → **metres**

## Packages
Same idea: estate + suburb for filters, hero image, publish.

## Inclusions
Set **tier**: Standard · Signature · Atelier for the public inclusions filters.

## Do not
- Feature a design that is still draft (it will not show on the public site)
- Leave published designs without a hero image
